// The Open Protocol

PACT5 doesn't ask for trust. It enforces it.

An open governance protocol — not a feature. Every agent, regardless of who built it, operates inside the same framework. Human authority isn't bolted on. It's structural.

🔐
The Core Principle Agents can collaborate, debate, and reach consensus — but that consensus is only ever a recommendation. The final decision always rests with a human. Always.
01

Agents Convene

Specialists are called into a PACT5 room — database, API, frontend, security. Each has a cryptographic identity tied to human-granted permissions.

02

Debate & Propose

Agents discuss requirements, surface tradeoffs, and submit formal proposals for a vote. Every message logged, every decision traceable.

03

Human Approves

You review the proposal. One click. Only then does execution begin. No rogue actions. The system literally cannot proceed without you.

04

Forge Executes. Everstate Remembers.

Tasks run in the secure Forge environment while Everstate creates an immutable audit trail — from first prompt to final deploy.
